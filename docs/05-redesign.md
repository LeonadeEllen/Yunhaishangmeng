# 重新设计：产业链、城镇、物流、港口画面、自由航行与空战

版本：2026-11-03 · 依据 Randolph 的四点需求（自由度、城镇建设与产业链、城市特色货、运输路线深度）。

参考的是这些游戏的**设计思路**，不照搬任何一款：
- 古典大航海经商游戏：进港是一座看得见的城镇，在街上点建筑办事；航海图可以自由开。
- 纪元 1800：岛屿地块决定能建什么；人口阶层消费货物、满足后升级；贸易路线是多站点、每站装卸。
- 异星工厂：产业链是"原料 → 半成品 → 成品"的有向图，瓶颈一目了然；吞吐量统计。
- 缺氧：物流按条件触发（存量高于/低于阈值才动作），而不是死循环。

## 1. 货物与产业链（第 5 轮）

17 种货，三级：

| 级 | 货物 |
|---|---|
| 原料（10） | 云麦、甜霞果、云鱼、云麻、玄铁矿、霞纹石、燃晶、雾珍珠、香木、灵参 |
| 半成品（4） | 精钢、琉璃、风帆布、丝云绸 |
| 成品（3） | 琉璃灯、霞露、云炮 |

配方（每座建筑每天）：

| 建筑 | 地块 | 投入 → 产出 |
|---|---|---|
| 麦田 / 果园 / 渔场 / 麻田 | 田、果、渔、麻 | → 原料 |
| 铁矿 / 石场 / 晶矿 / 珠场 / 香林 / 参园 | 矿、石、晶、珠、林、参 | → 原料 |
| 锻炉 | 工坊地 | 玄铁矿 2 + 燃晶 1 → 精钢 1 |
| 琉璃窑 | 工坊地 | 霞纹石 2 + 燃晶 1 → 琉璃 1 |
| 帆布坊 | 工坊地 | 云麻 2 → 风帆布 1 |
| 绸坊 | 工坊地 | 云麻 2 + 甜霞果 1 → 丝云绸 1 |
| 灯坊 | 工坊地 | 琉璃 1 + 精钢 1 → 琉璃灯 1 |
| 霞露坊 | 工坊地 | 灵参 1 + 甜霞果 1 + 琉璃 1 → 霞露 1 |
| 炮坊 | 工坊地 | 精钢 2 + 燃晶 1 → 云炮 1 |

- 建筑从你在该城的**仓库**取料，产出放回仓库；也可以设成"产出直接卖给本港"（本港收这种货时）。在母港还可以设成"直送灯塔工地"。
- 缺料时停工，界面标红并写明缺什么——瓶颈要一眼看见。

## 2. 城市：地块、招牌货与繁荣（第 5 轮）

- 每座城有一组**地块**（田、矿、林、工坊地……），地块决定能建什么。这是城市特色的来源：铁要去风月坞挖，珍珠只有霞鲸台有。
- 每座城的**交易所只收一部分货**（本地产的、本地要的、再加一两样过路货），不是什么都能买卖。货物清单就是这座城的"身份"。
- 每座城有一样**招牌货**：本地建筑生产它时产量 +25%。
- **繁荣度**（1–5 级）：城市每月检查它需要的货有没有供应充足；充足就涨，长期短缺就跌。繁荣度越高，需求越大、开放的地块越多。你给城市供货，就是在帮它长大，也在给自己的产业腾地方。
- 港主：在城里建筑最多的商会，其他商会在此买货多付 3%（沿用第 4 轮）。

## 3. 运输路线（第 6 轮）

- 一条航线 = 若干**停靠点**，每个停靠点若干条**指令**：
  - 买入 X：直到装满 / 直到船上有 N 件 / 只在价格 ≤ P 时
  - 卖出 X：全部 / 卖到船上剩 N 件 / 只在价格 ≥ P 时
  - 从仓库装 X：直到船上有 N 件 / 只装仓库里超过 N 件的部分（保留库存）
  - 卸入仓库 X：全部 / 直到仓库有 N 件
- 停靠条件：装满才走 / 最多等 N 天 / 立即出发。
- 每条航线显示每趟的运量、利润、空载率；地图上画出路线和方向。
- 同一条航线可以挂多艘船。

## 4. 港口画面（第 7 轮）

进港后是一整屏城镇插画，每座城布局不同（用原型的建筑美术拼出街景）：交易所、船坞、酒馆、商会银行、你的仓库、产业区、灯塔工地（母港）。点建筑进入对应界面；城里的人和船在动。

## 5. 自由航行与空战（第 8 轮）

- 航海图上可以点任意位置航行，不只是港口到港口；有风向、云流（顺流更快）、迷雾里的遗迹和漂流物。
- 遭遇云盗或对手时可以选：交战、逃跑、谈判。交战是简短的战术战：风向、侧舷炮（云炮）、接舷；船要装炮、配船员。
